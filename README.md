This repository contains a semantic function that outputs a cartesian product, written in Python.

## What is a Cartesian Product?
A Cartesian product combines two or more sets to form a set of ordered tuples, with each tuple containing one element from each set.
For example, the Cartesian product of `{1, 2}` and `{a, b}` is `{(1, a), (1, b), (2, a), (2, b)}`.

Learn more about it [on Wikipedia](https://en.wikipedia.org/wiki/Cartesian_product).
